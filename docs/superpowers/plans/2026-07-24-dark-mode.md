# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a real, fully-themed Dark Mode to DYOS with a Light/Dark/System selector in Settings, persisted across restarts.

**Architecture:** `AppPalette` becomes a Flutter `ThemeExtension<AppPalette>` with `light`/`dark` static instances registered on `AppTheme.light`/`AppTheme.dark` (`ThemeData`). A new `context.colors` extension resolves the active palette via `Theme.of(context).extension<AppPalette>()!`, replacing the static `AppTheme.colors` getter everywhere so every call site automatically picks up the current brightness. Theme mode choice is a persisted Riverpod `AsyncNotifier` backed by the existing `sharedPreferencesProvider`.

**Tech Stack:** Flutter `ThemeExtension`, `flutter_riverpod` + `riverpod_generator` (`@riverpod` codegen), `shared_preferences` (already a dependency).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-24-dark-mode-design.md` — follow it exactly; this plan implements it task-by-task.
- The static `AppTheme.colors` getter must be **deleted**, not deprecated — this makes an incomplete migration a compile error, not a silent bug (per spec's error-handling table).
- `flutter analyze` must stay at 0 errors/warnings after every task; `flutter test` must stay green (120 existing tests + new ones added here).
- No behavior change to light-mode visuals: `AppPalette.light`'s field values must be byte-identical to the current `AppPalette` constants in `lib/core/theme/app_theme.dart`.

```dart
    love: Color(0xFFFF6482),
    success: Color(0xFF32D74B),
    warning: Color(0xFFFFB340),
    shadow: Color(0x33000000),
  );

  @override
  AppPalette copyWith({
    Color? background,
    Color? card,
    Color? primary,
    Color? text,
    Color? textSecondary,
    Color? love,
    Color? success,
    Color? warning,

      warning: warning ?? this.warning,
      shadow: shadow ?? this.shadow,

  @override

    if (other is! AppPalette) return this;
    return AppPalette(

      warning: Color.lerp(warning, other.warning, t)!,
      shadow: Color.lerp(shadow, other.shadow, t)!,

  AppPalette get colors => Theme.of(this).extension<AppPalette>()!;

      useMaterial3: true,
      brightness: brightness,
      scaffoldBackgroundColor: palette.background,

        seedColor: palette.primary,
        primary: palette.primary,

        brightness: brightness,

      textTheme: GoogleFonts.interTextTheme(
        brightness == Brightness.dark ? ThemeData.dark().textTheme : ThemeData.light().textTheme,

      extensions: [palette],
    );

    return base.copyWith(
      cardTheme: CardThemeData(
        color: palette.card,
        elevation: 0,
        shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(24)),
        margin: EdgeInsets.zero,

          color: palette.text,

        backgroundColor: palette.primary,
        foregroundColor: Colors.white,
        shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(20)),
        elevation: 8,
      ),
    );
  }

  static ThemeData get light => _themeFor(AppPalette.light, Brightness.light);
  static ThemeData get dark => _themeFor(AppPalette.dark, Brightness.dark);

  static CupertinoThemeData get cupertinoLight {

      primaryColor: AppPalette.light.primary,
      scaffoldBackgroundColor: AppPalette.light.background,
      barBackgroundColor: AppPalette.light.card,
      textTheme: CupertinoTextThemeData(
```

```dart
import 'package:flutter/material.dart';
import 'package:riverpod_annotation/riverpod_annotation.dart';

import '../../features/auth/presentation/auth_providers.dart';

part 'theme_mode_provider.g.dart';

@riverpod
class ThemeModeController extends _$ThemeModeController {
  static const _prefsKey = 'themeMode';

  @override
  Future<ThemeMode> build() async {
    final prefs = await ref.watch(sharedPreferencesProvider.future);
    final saved = prefs.getString(_prefsKey);
    return switch (saved) {
      'light' => ThemeMode.light,
      'dark' => ThemeMode.dark,
      _ => ThemeMode.system,
    };
  }

  Future<void> setMode(ThemeMode mode) async {
    state = AsyncData(mode);
    final prefs = await ref.read(sharedPreferencesProvider.future);
    await prefs.setString(_prefsKey, mode.name);
  }
}
```
